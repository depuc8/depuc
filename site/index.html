NAME

depuc - writes C, C++ and Rust that survives crashes, sanitizers and code review, including GLib's

SYNOPSIS

depuc [--systems] [--rust] [--agents] [--scripting] [--web] [--open-source] problem

DESCRIPTION

I like knowing how things work under the hood, and most of my projects start as a question I couldn't stop thinking about. How does a web server handle a thousand connections without a thousand threads? That became hearth(8). What happens when a machine dies halfway through a job? That became flowd(8). Why is the loudest error in an outage so rarely the cause? That became logsleuth(1). I wanted to know how Redis and malloc actually work, so I wrote redislite(8) and dumalloc(3).

Lately the question is how you trust an LLM agent. evalkit(1) scores agent runs and fails CI when they get worse. procureagent(8) and research-crew(8) let the model reason and write while plain code checks it: policy decisions in one, citations in the other.

I also want to build open source that's useful to people. ember(1) puts Wikipedia and an AI model on a laptop, so someone in a remote area with bad or no internet can still look things up and ask questions, completely offline. I also send patches to GNOME, including GLib, the core library under nearly every GNOME app.

PROJECTS

flowd(8)distributed workflow scheduler

Runs DAGs of tasks across any number of worker processes that coordinate only through conditional writes to DynamoDB. Workers can crash at any moment: expired leases are reclaimed by the survivors, and fencing makes sure at most one result is ever committed per task.

C++20 · DynamoDB · CMake · CIgithub.com/depuc8/Flowd

evalkit(1)evaluate and debug LLM agents

Records every agent run as a trace and scores it for accuracy, groundedness, safety, cost and tool use. It can replay a failed step with a different prompt or model, and it fails CI when results drop below a saved baseline. LangGraph first, with a pytest plugin.

Python · LangGraph · pytest · on PyPIgithub.com/depuc8/EvalKit

ember(1)offline knowledge archives with a local LLM

Desktop app that reads Kiwix archives (Wikipedia, Project Gutenberg, Stack Exchange) and answers questions about them with a model running on your own machine. Nothing leaves the computer, and every answer cites the articles it used.

Rust · Tauri 2 · React · llama.cppgithub.com/depuc8/Ember

hearth(8)HTTP/1.1 server on bare POSIX sockets

One poll(2) loop holds every idle keep-alive connection while a fixed pool of workers answers requests, so a thousand idle clients cost no threads. About 2,400 lines and 151 tests that run clean under ASan, UBSan and TSan.

C++17 · POSIX · CI · coveragegithub.com/depuc8/hearth

procureagent(8)multi-agent procurement assistant

Describe a purchase and a planner hands it to vendor search, contract review and approval agents, then a critic loop checks the draft. Vendor ranking, contract risk and policy decisions are plain code the model can't override, so it can't recommend a vendor that policy rejected.

Python · Google ADK · Gemini · BigQuery · Cloud Rungithub.com/depuc8/ProcureAgent

research-crew(8)cited literature reviews from papers

Reader, analyst and writer agents pull papers from PDFs or arXiv, search them through Vertex AI Vector Search, and draft a literature review. Every [paper, page] citation is checked against the chunks the agents actually retrieved, and claims that fail are dropped.

Python · CrewAI · Vertex AI · Terraformgithub.com/depuc8/CrewAI-Research-Crew

redislite(8)in-memory key-value server

A Redis-style server with a non-blocking event loop, a custom binary protocol, TTL expiry on a heap, and sorted sets built on an AVL tree. No external dependencies.

C++17github.com/depuc8/RedisLite

logsleuth(1)log analyzer and root-cause finder

Point it at syslog and app logs: awk parses them into one stream, sed collapses messages into signatures, and spikes are flagged against a median/MAD baseline. The RCA report names the first thing that went abnormal, not the loudest.

Bash · awk · sed · Pythongithub.com/depuc8/LogSleuth

graphplotter(1)type an equation, get a graph

Hand-written expression parser that understands implicit multiplication (2x, x sin(x)), drawn with SDL3 and free to zoom and pan.

C++17 · SDL3github.com/depuc8/GraphPlotter

dumalloc(3)a heap allocator

malloc and free over a static arena: an implicit free list with first-fit placement, block splitting and coalescing.

C99github.com/depuc8/dumalloc

HISTORY

It started with Need for Speed: Most Wanted. I wanted infinite cash, found it sitting in memory as a plain number, and changed it. After that, software looked like something I could open up.

Then came a Raspberry Pi Zero 2 W: low-level experiments, job scheduling, and a tiny home lab running my network.

Now I build the things I used to poke at: servers, allocators, schedulers, and patches for GNOME.
